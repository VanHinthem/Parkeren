# Gebruikershandleiding

## Parkeren

Na inloggen toont het dashboard de actuele parkeerstatus.

- Zonder actieve parkeeractie kies je een toegewezen kenteken en een beschikbare parkeerduur en kies je **Start parkeren**.
- Bij een actieve parkeeractie zie je de verstreken tijd en gewenste eindtijd.
- **Stoppen** beëindigt de parkeeractie na bevestiging wanneer handmatig stoppen volgens het parkeerbeleid is toegestaan.
- **Verlengen** wijzigt de gewenste eindtijd binnen de geldende parkeerregels.
- Tijdens bevestiging door de parkeerprovider blijven status en parkeeractie zichtbaar. De app vernieuwt deze status automatisch.
- De capaciteitskaart toont hoeveel gelijktijdige parkeeracties in gebruik zijn. Starten is niet beschikbaar wanneer de capaciteit vol of onbekend is.
- **Recente parkeeracties** toont de laatste afgeronde acties; via **Alles bekijken** open je de parkeerhistorie.

De server controleert kenteken, parkeerbeleid, parkeerregels en capaciteit altijd opnieuw. Een uitgeschakelde actie of foutmelding geeft daarom geen recht om de parkeeractie op een andere manier uit te voeren.
